# Python Programming Assignments

A structured collection of Python exercises covering functions, numbers, strings, loops, and patterns — organized into four sections by topic and difficulty.

---

## 📁 Sections

### Section A – Basic Functions and Numbers
| # | Problem | Key Concepts |
|---|---------|--------------|
| 1 | Even or Odd | `if-else`, `%` |
| 2 | Positive, Negative or Zero | `if-elif-else` |
| 3 | Find Largest of Two Numbers | `return`, conditional |
| 4 | Find Largest of Three Numbers | conditionals (no `max()`) |

## 🚀 Getting Started

**Requirements:** Python 3.x — no external libraries needed.

**Run any file:**
```bash
python filename.py
```

---

## 📌 Constraints Summary

Several problems have explicit restrictions to encourage learning fundamentals:
- No `max()`, `len()`, `split()`, `count()`, `replace()` where restricted
- No recursion for factorial
- No external libraries for prime check
- Loop-based solutions preferred over one-liners where specified
